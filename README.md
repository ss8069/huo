# Фиксация товаров — мобильное приложение

Один файл `index.html`, работает без сервера и сборки.

## Как протестировать на телефоне через GitHub

1. Создайте репозиторий на GitHub, загрузите в него `index.html` из этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
3. Через минуту откройте `https://<логин>.github.io/<репозиторий>/` на телефоне.
4. Разрешите доступ к камере при первом снимке. Камера работает только по HTTPS — GitHub Pages его даёт.
5. На iPhone: Safari → «Поделиться» → «На экран Домой» — откроется без адресной строки.

Данные (карточки, фото) хранятся локально в браузере телефона.
